Pitch

● XenoScript

Validated before you ever see it.

An AI coding assistant for languages no model has ever seen.

Why this exists

No model was trained on your hospital's 40-year-old scripting language.

MUMPS is almost undocumented in public, and the developer pool that knows it is shrinking fast. General-purpose AI assistants hallucinate its syntax constantly — they've barely seen it.

The insight

We didn't train a bigger model. We gave it a way to check its own work.

Retrieve real examples. Generate a candidate. Verify it against a real compiler or interpreter. Repair on failure. Cache what's actually proven — not just what ran without crashing.

How it works

Five steps. Every one of them real.

01

Retrieve

Grep the language's own corpus. Nothing invented.

02

Generate

The local model drafts a candidate.

03

Verify

Run it for real, against a real toolchain.

04

Repair

Feed the real error back. Up to 4 tries.

05

Cache

Only proven solutions get reused as examples.

Built by finding real bugs, not hiding them

Every claim in this deck was re-tested live before it was written down.

Root-caused & fixed

The trailing newline that ate the output

The interpreter silently discarded the last piped line when source didn't end in a newline. Exit 0, no error, no output.

Root-caused & fixed

The cache that poisoned itself

A structurally-wrong-but-error-free generation could get cited as an example for the next prompt. Now only ground-truth-checked rows are ever cited.

Root-caused & fixed

ELSE needs two spaces, not one

A genuine interpreter grammar quirk. Now normalized mechanically, and the fix flows all the way back to what you see.

Architecture, in one line

corpora/<name>/ — docs, examples, a toolchain. That's the whole surface.

Three local processes: a model server (Ollama, fully offline), an MCP server exposing five generic search-and-verify tools, and a harness that wires them into generate → verify → repair. No fine-tuning, no cloud, no unverified code ever shown to the user.
